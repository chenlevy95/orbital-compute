The same ID does not mean a duplicate charge.

store_record() matches on record_id, then compares updated_at. These illustrative records use one ID, demo-usage-001.

Before these decisions: validate_record() checks required fields, the requested date range, final/void status, and finite numbers. Timestamps must be exactly YYYY-MM-DDTHH:MM:SSZ and are kept unchanged. Amounts become canonical decimal text, so 12.00 and 12 compare equally.
